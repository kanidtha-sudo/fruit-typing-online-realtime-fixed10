# สวนคำผลไม้ — เกมพิมพ์คำศัพท์ออนไลน์แบบ Realtime

ไฟล์นี้ถูกปรับให้:
- ใช้คำศัพท์ชุดใหม่ตามที่กำหนด
- นักเรียนหลายเครื่องเข้า URL เดียวกันได้
- เมื่อเล่นจบ คะแนนจะส่งเข้าเซิร์ฟเวอร์ทันที
- หน้าครูเห็นคะแนนจากทุกเครื่องแบบ Realtime
- ปุ่มล้างคะแนนล้างข้อมูลให้ทุกเครื่องพร้อมกัน
- เก็บคะแนนไว้ใน `records.json` เพื่อให้เซิร์ฟเวอร์อ่านกลับมาได้หลังรีสตาร์ต (ขึ้นอยู่กับพื้นที่จัดเก็บของผู้ให้บริการโฮสต์)

## รันบนเครื่อง
```bash
npm install
npm start
```
จากนั้นเปิด `http://localhost:10000`

## นำขึ้น Render
สร้าง Web Service จากโฟลเดอร์นี้ แล้วตั้งค่า:
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `TEACHER_PIN` = รหัสครูที่ต้องการ

Render จะให้ URL เดียว เช่น `https://ชื่อโปรเจกต์.onrender.com` นักเรียนและครูใช้ URL เดียวกัน

> หมายเหตุ: `records.json` เป็นการเก็บข้อมูลแบบไฟล์บนเซิร์ฟเวอร์ หากต้องการเก็บคะแนนถาวรบนโฮสต์ที่มี ephemeral filesystem ควรต่อฐานข้อมูลภายหลัง เช่น PostgreSQL/Redis
